## 👨‍💻 About Me

Computer Systems Engineering (ISC) undergrad at **Universidad Autónoma de Tamaulipas (UAT)**, **Oracle Academy Mentee**, and Mobile Software Engineer at **Código Late**. 

While I ship cross-platform mobile and backend systems in production, my core technical focus is **LLM inference internals, memory-efficient model execution, and systems programming in Rust and C++**. I enjoy working close to the metal—inspecting raw tensor layouts, analyzing low-bit quantization trade-offs, and building deterministic tooling for AI workflows.

- 🔬 **Current Research:** Bachelor's thesis on **Generative AI & Software Architecture**, alongside hands-on exploration of ternary and low-bit LLM quantization (`BitNet b1.58`, `GPTQ`, `OmniQuant`).
- 🧠 **Algorithmic Background:** Active competitive programmer (**ICPC Gran Premio de México**, **TamCoder 2026**) and contest organizer on OmegaUp.
- ⚙️ **Daily Driver:** CachyOS Linux + Hyprland, terminal-first workflows, and local LLM orchestration.
